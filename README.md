# TAG Post Assets (public, temporary)

Images for TAG posts (X and other platforms), uploaded by the TAG posting Bots.

**Temporary:** this repo lives on GitHub until Neil's home server becomes the source of truth.

## Rules for Bots
- Add only. Never delete, force-push, rewrite history or touch any other repo.
- Layout: approved brand assets in `brand/`; post images in `posts/YYYY-MM/<post-or-batch>/` (e.g. `posts/2026-11/day1-final/x-fb/`). Superseded images are not uploaded.
- One commit per post: `post: <post-slug> (<n> images)`.
- No secrets, tokens, personal data or unreleased private product material that Neil hasn't approved for posting.

## Visibility
Public since 3 Nov 2026 at Neil's request, so Buffer can use the image links. Everything here is treated as publishable, so only upload images approved for posting.
