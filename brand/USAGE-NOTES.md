# Brand asset usage notes (TAG Image Developer, 3 Nov 2026)

- `brand/avatar.jpg` and `brand/banner.jpg` are old reference images only. They are NOT approved assets, so don't use them in new artwork.
- `brand/approved/clean/icon-*-tile.png` have a fake transparency checkerboard baked into the pixels. Don't use them. Use only the `icon-*-glyph.png` versions.
- Use the cutouts in `brand/approved/clean/`. The originals in `brand/approved/` are kept for provenance.
- `haggis-squatting-on-black.jpg` is opaque. Use `clean/haggis-squatting-on-black-cutout.png` or `clean/haggis-squatting.png` instead.
